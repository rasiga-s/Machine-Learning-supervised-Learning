# Machine Learning Algorithms Summary

## 1. Regression Algorithms

| No. | Algorithm                   | Simple Explanation                                 | Example                                 |
|-----|-----------------------------|----------------------------------------------------|-----------------------------------------|
| 1   | Linear Regression           | Predicts values using a straight-line relationship | House price                             |
| 2   | Multiple Linear Regression  | Uses multiple input features to predict a value    | Salary based on experience and skills   |
| 3   | Polynomial Regression       | Models curved relationships                        | Sales growth                            |
| 4   | Decision Tree Regression    | Predicts values using decision rules               | Car price                               |
| 5   | Random Forest Regression    | Combines multiple trees and averages their predictions | House price prediction              |

## 2. Classification Algorithms

| No. | Algorithm                   | Simple Explanation                                 | Example                |
|-----|-----------------------------|----------------------------------------------------|------------------------|
| 1   | Logistic Regression         | Predicts class probabilities                       | Purchase: Yes/No       |
| 2   | K-Nearest Neighbors (KNN)   | Predicts based on similar nearby examples          | Fruit classification   |
| 3   | Decision Tree Classifier    | Uses decision rules to predict a class             | Loan approval          |
| 4   | Random Forest Classifier    | Combines multiple trees using majority voting      | Customer churn         |
| 5   | Support Vector Machine (SVM)| Separates classes using a decision boundary        | Spam detection         |
| 6   | Naive Bayes                 | Uses probability to classify data                  | Spam/Not Spam          |
